# example-deck

A three-slide example for the deck pipeline. Build it with `bash scripts/build-deck.sh projects/example-deck_ppt169_20261112`.
The published copy is `docs/deck/example-deck.pptx`. Replace this deck with your own, or delete the folder, the
published file and its note in `site/manifest.json`.

The visual system: white background, Georgia titles at 44, Arial body text, green `#0F6B4F` for the bar and the
bullets, `#17A67A` for the kicker. The canvas is 1280 by 720.
