# example-video

A nine-second, two-scene example for the video pipeline. Build it with `bash scripts/build-video.sh video/example-video`.
The published copy is `docs/video/example-video.mp4`. Replace this video with your own, or delete the folder, the
published file and its note in `site/manifest.json`.

`AGENTS.md` and `CLAUDE.md` in this folder were written by `hyperframes init`. They are that tool's own rules for an
agent that works inside a video project.
